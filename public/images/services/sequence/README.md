# Fotogramas definitivos de Servicios

Usa `desktop/frame-0001.webp` y `mobile/frame-0001.webp` hasta el último fotograma, con numeración consecutiva de cuatro dígitos y la misma cantidad en ambas carpetas. Activa la secuencia cambiando `frameCount` en `src/data/service-sequence.ts`.

Mientras `frameCount` sea `0`, la página utiliza las cinco fotografías provisionales existentes y no solicita archivos de estas carpetas.
